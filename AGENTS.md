# AGENTS.md

Instructions for AI coding agents working in this repository.

JSON Schemas and synthetic examples for every Trailboss command's `--json` output, and the versioning rules.

## This repository is public

Everything here, commit messages included, is public. Trailboss's CLI is closed source, and nothing here may reveal what isn't already public:

- Never copy in the CLI's code, or describe how it works inside: heuristics, thresholds, internal structure, the prompts it writes. Write about what a command does and outputs, for a user.
- Nothing about plans, the roadmap, unreleased features (beyond what this repository's own work needs) or pricing.
- No issue numbers or links except to this organization's public repositories.
- No real transcripts, paths, session IDs, names, emails or tokens. Examples and fixtures are synthetic.
- A schema describes the output, not how it's computed.
- Pushing a schema publishes its command before the release. Hold back one that should stay unannounced until its release day.
